# HANA AI OFFICE V1

狀態：規劃與隔離開發區（未部署、未連接正式資料）

這是 HANA AI OFFICE 在 GitHub 的**暫存開發位置**。因目前 GitHub 連接器沒有建立新 Repository 的功能，本資料夾建立於 `helga-at-manager` 的獨立分支 `hana-ai-office-v1`，**不是**該學員管理系統的一部分，也不得合併到 main。未來找到正式 HANA FOCUS 專案後，再遷移至其獨立專案或新 Repository。

## 產品原則
- 使用者角色：Founder & Creative Director；AI 承接專案協調、資訊整理與行政建議。
- 事業領域 → 專案 → 任務 → 下一步行動。
- 今日只推薦 1–3 項需要本人執行的高價值工作。
- Idea Inbox 預設不建立任務；需經人工確認。
- 半自主權限：內部整理與草稿可自動；對外、金流、正式部署等均須審核或禁止。
- 每週 35 小時為彈性參考，優先保留創作與策略工作。

## 目錄
- `docs/architecture.md`：功能分層、權限、資料表與執行順序
- `docs/implementation-checklist.md`：V1 建置及驗收清單

## 隔離規則
1. 不修改既有 `index.html`、學員資料或正式部署設定。
2. 未經確認不合併本分支。
3. 不將 API 金鑰、客戶資料或訂單資料提交至 Git。
4. 未確認正式 HANA FOCUS 原始碼前，不宣稱已部署 AI 工作板。
